## 第一章：项目概述

### 1.1 项目背景

随着高校规模的不断扩大和信息化建设的深入发展，传统的校园健康管理模式已经无法满足现代化校园的需求。**智慧校园健康管理系统**应运而生，旨在通过信息技术手段，构建一个覆盖全校师生的综合性健康服务平台。

### 1.2 项目定位

本系统定位为**一站式校园健康服务综合平台**，集成以下核心能力：

| 核心能力 | 描述 |
|:---|:---|
| 🏥 **健康管理** | 师生健康档案建档、体检数据管理、健康状态追踪 |
| 💊 **医疗服务** | 在线购药、校医预约、紧急呼叫、就诊记录 |
| 📊 **数据分析** | 健康数据可视化、预警趋势分析、决策支持 |
| 🛒 **智慧药房** | 电商购物流程、聚合支付、订单管理 |
| 📢 **消息通知** | 健康预警推送、通知公告发布、邮件系统 |
| 🌤️ **智能服务** | 天气预报、地理定位、健康建议、AI助手 |

### 1.3 项目目标

#### 核心目标

1. **提升效率**: 实现健康管理流程全面数字化，减少人工操作
2. **保障安全**: 构建完善的健康预警机制，及时发现异常情况
3. **优化体验**: 提供便捷的自助服务，提升师生满意度
4. **辅助决策**: 通过数据可视化，为管理层提供决策支持

#### 预期效果

- ✅ 健康档案电子化率达到 **100%**
- ✅ 健康预警响应时间缩短至 **5分钟内**
- ✅ 药品购买流程简化至 **3步完成**
- ✅ 数据查询效率提升 **80%**

### 1.4 系统特色

#### 🎯 四大核心特色

**1. 多角色权限体系**

- 支持管理员、教师、学生、家长、后勤5种角色
- 基于RBAC的动态权限控制
- 路由级别的权限隔离

**2. 全流程电商系统**

- 完整的购物车-下单-支付-配送流程
- 集成支付宝沙箱支付
- 订单状态实时追踪

**3. 智能数据分析**

- ECharts可视化大屏
- 多维度健康数据统计
- 预警趋势智能预测

**4. 现代化技术栈**

- Vue 3 Composition API
- TypeScript 强类型约束
- Vite 极速开发体验

### 1.5 系统用户

| 用户角色 | 用户数量 | 主要诉求 |
|:---|:---:|:---|
| **管理员** | 10-20人 | 系统管理、数据监控、决策支持 |

### 2.4 数据流架构

```
用户操作
   ↓
Vue 组件触发 Action
   ↓
调用 API 方法 (src/api)
   ↓
Axios 发送 HTTP 请求
   ↓
请求拦截器 (添加 Token)
   ↓
后端 Spring Boot
   ↓
响应拦截器 (处理响应)
   ↓
更新 Pinia Store
   ↓
组件响应式更新
   ↓
视图重新渲染
```

### 2.5 安全架构

#### 认证与授权

```
用户登录
   ↓
后端验证用户名密码
   ↓
生成 JWT Token
   ↓
前端存储 Token (LocalStorage)
   ↓
每次请求携带 Token
   ↓
后端验证 Token
   ↓
根据角色返回对应权限路由
   ↓
前端动态加载路由
```

#### 安全措施

| 措施 | 实现方式 |
|:---|:---|
| **Token 鉴权** | JWT Token + 请求拦截器 |
| **路由守卫** | beforeEach 全局守卫 |
| **HTTPS** | 生产环境强制 HTTPS |
| **XSS 防护** | Vue 自动转义 + CSP |
| **CSRF 防护** | Token 机制 |
| **权限隔离** | 基于角色的动态路由 |

#### 3.2.5 预警通知模块

**功能概述**  
基于健康数据的智能预警系统。

**预警类型**

| 预警类型 | 触发条件 | 处理流程 |
|:---|:---|:---|
| 🌡️ **体温异常** | 体温 > 37.5℃ | 立即通知学生、家长、辅导员 |
| ❤️ **心率异常** | 心率 < 60 或 > 100 | 健康提示 + 建议就医 |
| 💤 **睡眠不足** | 睡眠时间 < 6小时/天 | 健康建议推送 |
| 🏃 **运动不足** | 每日步数 < 5000步 | 运动建议推送 |
| ⚖️ **BMI异常** | BMI < 18.5 或 > 24 | 营养建议 + 体检建议 |

**预警流程**

```
健康数据采集
   ↓
预警规则引擎判断
   ↓
触发预警
   ↓
生成预警记录
   ↓
多渠道推送 (站内消息 + 邮件 + 短信)
   ↓
管理员/家长接收
   ↓
处理跟踪记录
```

```typescript
const startStream = async (message: string, chatId: string, options) => {
    const url = generateStreamUrl(message, chatId, options)

    const response = await fetch(url, {
        signal: abortController.signal
    })

    const reader = response.body.getReader()
    const decoder = new TextDecoder('utf-8')

    while (true) {
        const {done, value} = await reader.read()
        if (done) break

        const chunk = decoder.decode(value, {stream: true})
        const lines = chunk.split('\n')

        for (const line of lines) {
            if (line.startsWith('data:')) {
                const data = line.substring(5).trim()
                options.onChunk(data) // 回调更新UI
            }
        }
    }

    options.onComplete()
}
```

**封装架构**

```typescript
// src/utils/request.ts
import axios from 'axios'
import {useUserStore} from '@/store/modules/user'
import {ElMessage} from 'element-plus'
import router from '@/router'

const request = axios.create({
    baseURL: '/api',
    timeout: 10000
})

// 请求拦截器
request.interceptors.request.use(
    (config) => {
        const userStore = useUserStore()
        if (userStore.token) {
            config.headers.Authorization = userStore.token
        }
        return config
    },
    (error) => Promise.reject(error)
)

// 响应拦截器
request.interceptors.response.use(
    (response) => {
        const {code, data, message} = response.data
        if (code === 200) {
            return data
        } else {
            ElMessage.error(message)
            return Promise.reject(new Error(message))
        }
    },
    async (error) => {
        if (error.response?.status === 401) {
            ElMessage.warning('登录超时')
            await useUserStore().logout()
            router.push('/login')
        }
        return Promise.reject(error)
    }
)

export default request
```

```typescript
            next({path: '/'})
        } else {
            const hasRoles = UserStore.roles && UserStore.roles.length > 0

            if (hasRoles) {

                    const accessRoutes = await PermissionStore.generateRoutes(roles)

                    // 动态添加路由
                    accessRoutes.forEach((route) => {
                        router.addRoute(route)
                    })

                    next({...to, replace: true})
                } catch (error) {
                    await UserStore.logout()
                    next(`/login?redirect=${to.path}`)
                }
            }
        }
    } else {
        // 未登录 - 跳转登录页
        if (to.path === '/login') {
            next()
        } else {
            next(`/login?redirect=${to.path}`)
        }
    }
})
```

```typescript
                ...message,
                id: `msg_${Date.now()}_${Math.random()}`,
                timestamp: Date.now()

                session.lastMessage = message.content
            }

            return newMessage
        },

            if (message) {
                message.content = content
```

### 5.3 AI对话流式实现

#### 5.3.1 Fetch + TextDecoder 方案

```typescript
// src/parent-views/ai-chat/composables/useStreamChat.ts
import { ref } from 'vue'

export interface StreamChatOptions {
  enableWebSearch?: boolean
  enableDeepThinking?: boolean
  onChunk: (chunk: string) => void
  onComplete: () => void
  onError: (error: Error) => void
}

export function useStreamChat() {
  const abortController = ref<AbortController | null>(null)
  const connectionStatus = ref<'IDLE' | 'CONNECTING' | 'CONNECTED' | 'ERROR'>('IDLE')
  
  const startStream = async (
    message: string,
    chatId: string,
    options: StreamChatOptions
  ) => {
    try {
      // 创建 AbortController 用于取消请求
      abortController.value = new AbortController()
      
      // 生成流式请求 URL
      const url = generateStreamUrl(message, chatId, options)
      
      connectionStatus.value = 'CONNECTING'
      
      // 发起 Fetch 请求
      const response = await fetch(url, {
        method: 'GET',
        signal: abortController.value.signal
      })
      
      if (!response.ok) {
        throw new Error(`HTTP error! status: ${response.status}`)
      }
      
      connectionStatus.value = 'CONNECTED'
      
      // 获取 Reader
      const reader = response.body!.getReader()
      const decoder = new TextDecoder('utf-8')
      
      let buffer = ''
      
      // 读取流式数据
      while (true) {
        const { done, value } = await reader.read()
        
        if (done) {
          break
        }
        
        // 解码数据 (UTF-8 编码,支持中文)
        buffer += decoder.decode(value, { stream: true })
        
        // 按行分割
        const lines = buffer.split('\n')
        buffer = lines.pop() || '' // 保留不完整的行
        
        // 处理每一行
        for (const line of lines) {
          if (line.trim().startsWith('data:')) {
            const data = line.substring(5).trim()
            if (data && data !== '[DONE]') {
              options.onChunk(data)
            }
          }
        }
      }
      
      // 流式完成
      options.onComplete()
      connectionStatus.value = 'IDLE'
      
    } catch (error: any) {
      if (error.name === 'AbortError') {
        console.log('流式请求已取消')
      } else {
        console.error('流式请求错误:', error)
        connectionStatus.value = 'ERROR'
        options.onError(error)
      }
    }
  }
  
  const stopStream = () => {
    if (abortController.value) {
      abortController.value.abort()
      abortController.value = null
    }
  }
  
  return {
    startStream,
    stopStream,
    connectionStatus
  }
}
```

#### 5.5.1 购物车逻辑

```typescript
// src/parent-views/store/composables/useCart.ts
import {ref, computed} from 'vue'

interface CartItem {
    id: string
    name: string
    price: number
    quantity: number
    image: string
    checked: boolean
}

export function useCart() {
    const cartItems = ref<CartItem[]>([])

    // 添加到购物车
    const addToCart = (item: Omit<CartItem, 'checked'>) => {
        const existingItem = cartItems.value.find(i => i.id === item.id)

        if (existingItem) {
            existingItem.quantity += item.quantity
        } else {
            cartItems.value.push({...item, checked: true})
        }
    }

    // 更新数量
    const updateQuantity = (id: string, quantity: number) => {
        const item = cartItems.value.find(i => i.id === id)
        if (item) {
            item.quantity = Math.max(1, quantity)
        }
    }

    // 删除商品
    const removeItem = (id: string) => {
        const index = cartItems.value.findIndex(i => i.id === id)
        if (index !== -1) {
            cartItems.value.splice(index, 1)
        }
    }

    // 切换选中状态
    const toggleCheck = (id: string) => {
        const item = cartItems.value.find(i => i.id === id)
        if (item) {
            item.checked = !item.checked
        }
    }

    // 全选/取消全选
    const toggleAllCheck = () => {
        const allChecked = cartItems.value.every(i => i.checked)
        cartItems.value.forEach(item => {
            item.checked = !allChecked
        })
    }

    // 计算总价
    const totalPrice = computed(() => {
        return cartItems.value
            .filter(i => i.checked)
            .reduce((sum, item) => sum + item.price * item.quantity, 0)
    })

    // 选中数量
    const checkedCount = computed(() => {
        return cartItems.value.filter(i => i.checked).length
    })

    return {
        cartItems,
        addToCart,
        updateQuantity,
        removeItem,
        toggleCheck,
        toggleAllCheck,
        totalPrice,
        checkedCount
    }
}
```

```typescript
// src/api/parent/aiChat.ts
import request from '@/utils/request'

// 生成健康报告
export const generateHealthReport = (userId: string, userName: string) => {
    return request.post('/health/report', {userId, userName})
}

// 生成 ChatId
export const generateChatId = (userId: string) => {
    return `chat_${userId}_${Date.now()}`
}

// 生成流式 URL
export const generateStreamUrl = (
    message: string,
    chatId: string,
    options?: {
        enableWebSearch?: boolean
        enableDeepThinking?: boolean
    }
) => {
    const baseUrl = '/api/ai/health_app/chat'

    if (options?.enableWebSearch || options?.enableDeepThinking) {
        const params = new URLSearchParams({
            question: message,
            chatId,
            enable_web_search: String(options.enableWebSearch || false),
            enable_deep_thinking: String(options.enableDeepThinking || false)
        })
        return `${baseUrl}/advanced/stream?${params}`
    } else {
        const params = new URLSearchParams({
            question: message,
            chatId
        })
        return `${baseUrl}/sse?${params}`
    }
}
```

### 附录C：常见问题

**Q1: 忘记密码怎么办?**
A: 联系系统管理员重置密码。

**Q2: 支付失败怎么办?**
A: 检查网络连接,如果问题依然存在,联系客服处理。

**Q3: 健康数据多久更新一次?**
A: 手动录入的数据即时更新,智能设备同步的数据通常每小时更新一次。

**Q4: 如何绑定子女账号?**
A: 家长登录后,进入"账号管理",输入子女学号即可绑定。

**Q5: AI助手是否收费?**
A: 基础对话免费,高级功能(联网搜索、深度思考)可能需要付费。
