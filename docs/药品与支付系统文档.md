### 2.3 Service层实现

#### DrugsServiceImpl.java 核心方法

```java
@Service
@AllArgsConstructor
public class DrugsServiceImpl extends ServiceImpl<DrugsMapper, Drugs> 
        implements DrugsService {

    private DrugsMapper drugsMapper;

    /**
     * 分页搜索药品
     */
    @Override
    public Page<Drugs> searchDrugs(PageQuery pageQuery, String id, String name, 
                                    String type, String startTime, String endTime) {
        int size = pageQuery.getSize();
        int offset = ((pageQuery.getCurrent() - 1) * size);
        String orders = pageQuery.getOrders();
        Boolean isAsc = pageQuery.getIsAsc();
        
        // 查询数据
        List<Drugs> list = drugsMapper.searchDrugs(size, offset, orders, isAsc, 
                                                     id, name, type, startTime, endTime);
        // 统计总数
        int total = drugsMapper.countDrugs(id, name, type, startTime, endTime);
        
        // 封装分页结果
        Page<Drugs> drugsPage = new Page<>();
        drugsPage.setRecords(list);
        drugsPage.setTotal(total);
        drugsPage.setPages((int) Math.ceil((double) total / size));
        
        return drugsPage;
    }

    /**
     * 删除药品
     */
    @Override
    public boolean removeDrugsByDid(String did) {
        int result = drugsMapper.deleteByDrugId(did);
        return result > 0;
    }

    /**
     * 更新药品
     */
    @Override
    public boolean updateBydrugId(Drugs drugs) {
        int result = drugsMapper.updateByDrugId(drugs);
        return result > 0;
    }

    /**
     * 添加药品
     */
    @Override
    public boolean saveDrugs(Drugs drugs) {
        int result = drugsMapper.insertDrugs(drugs);
        return result > 0;
    }
}
```

### 3.2 支付核心接口

#### 💰 发起支付

```http
GET /pay/alipay
```

**请求参数**：

```
dona_drugId: 药品ID（或订单号）
dona_money: 支付金额（元）
dona_sum: 购买数量

```

**完整URL示例**：

```
http://localhost:8081/pay/alipay?dona_drugId=D001&dona_money=15.50&dona_sum=2&dona_userId=U001
```

**业务流程**：

```java
@ResponseBody
@RequestMapping("/pay/alipay")
public String alipay(HttpSession session,
                     @RequestParam(value = "dona_drugId") String dona_drugId,
                     @RequestParam(value = "dona_money") float dona_money,
                     @RequestParam(value = "dona_sum") int dona_sum,
                     @RequestParam(value = "dona_userId") String dona_userId) 
                     throws AlipayApiException {
    
    // 1. 查询药品名称
    Page<Drugs> drugsPage = drugsService.searchDrugs(new PageQuery(), dona_drugId, 
                                                       null, null, null, null);
    String name = drugsPage.getRecords().get(0).getName();
    
    // 2. 生成订单号（支付宝要求）
    String time = new SimpleDateFormat("yyyyMMddHHmmss").format(new Date());
    String user = UUID.randomUUID().toString().replace("-", "").toUpperCase();
    String OrderNum = time + user;  // 最终订单号
    
    // 3. 保存订单信息到session（支付成功后使用）
    session.setAttribute("dona_userId", dona_userId);
    session.setAttribute("dona_money", dona_money);
    session.setAttribute("dona_drugId", dona_drugId);
    session.setAttribute("dona_sum", dona_sum);
    session.setAttribute("dona_id", user);
    session.setAttribute("dona_name", name);
    
    // 4. 计算总金额
    dona_money = dona_money * dona_sum;
    
    // 5. 调用支付宝接口
    String dona_name = orderService.findID(dona_drugId);
    return sendRequestToAlipay(OrderNum, dona_money, dona_name, name);
}
```

**支付宝接口调用**：

```java
private String sendRequestToAlipay(String outTradeNo, Float totalAmount, 
                                   String subject, String name) 
                                   throws AlipayApiException {
    // 1. 初始化支付宝客户端
    AlipayClient alipayClient = new DefaultAlipayClient(
        GATEWAY_URL, APP_ID, APP_PRIVATE_KEY, FORMAT, 
        CHARSET, ALIPAY_PUBLIC_KEY, SIGN_TYPE
    );
    
    // 2. 创建支付请求
    AlipayTradePagePayRequest alipayRequest = new AlipayTradePagePayRequest();
    alipayRequest.setReturnUrl(RETURN_URL);   // 同步回调
    alipayRequest.setNotifyUrl(NOTIFY_URL);   // 异步回调
    
    // 3. 设置业务参数
    String body = "药品";
    alipayRequest.setBizContent("{"
        + "\"out_trade_no\":\"" + outTradeNo + "\","      // 商户订单号
        + "\"total_amount\":\"" + totalAmount + "\","     // 支付金额
        + "\"subject\":\"" + subject + "\","              // 订单标题
        + "\"body\":\"" + body + "\","                    // 订单描述
        + "\"product_name\":\"" + name + "\","            // 商品名称
        + "\"product_code\":\"FAST_INSTANT_TRADE_PAY\"}"); // 产品码（电脑网站支付）
    
    // 4. 发送请求，返回HTML页面（包含支付二维码）
    String result = alipayClient.pageExecute(alipayRequest).getBody();
    return result;
}
```

**返回值**：返回一个包含支付宝二维码的HTML页面，前端会在新窗口打开该页面。

@GetMapping("nofity")
public String notify(HttpSession session) {
    System.out.println("支付成功");
    
    // 1. 从session获取订单信息
    String dona_id = (String) session.getAttribute("dona_id");
    String dona_userId = (String) session.getAttribute("dona_userId");
    String dona_drugId = (String) session.getAttribute("dona_drugId");
    float dona_money = (float) session.getAttribute("dona_money");
    Integer dona_sum = (Integer) session.getAttribute("dona_sum");
    
    // 2. 创建订单记录
    Orders orders = new Orders();
    orders.setOrderId(dona_id);
    orders.setUserId(dona_userId);
    orders.setDrugId(dona_drugId);
    orders.setPrice(BigDecimal.valueOf(dona_money));
    orders.setQuantity(dona_sum);
    orders.setTime(new Date());
    orders.setTotalPrice(BigDecimal.valueOf(dona_money * dona_sum));
    orders.setCreateTime(new Date());
    orders.setUpdateTime(new Date());
    orders.setOrderStatus("已支付");
    
    // 3. 保存订单到数据库
    orderService.save(orders);
    
    // 4. 重定向到前端首页
    return "redirect:http://localhost:5173/index";
}

### 8.2 缓存策略

```java
@Service
public class DrugsServiceImpl {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 缓存热门药品
     */
    public Drugs getDrugById(String drugId) {
        String key = "drug:" + drugId;
        
        // 1. 先查缓存
        Drugs drugs = (Drugs) redisTemplate.opsForValue().get(key);
        if (drugs != null) {
            return drugs;
        }
        
        // 2. 查数据库
        drugs = drugsMapper.selectById(drugId);
        
        // 3. 存入缓存（1小时）
        redisTemplate.opsForValue().set(key, drugs, 1, TimeUnit.HOURS);
        
        return drugs;
    }
}
```
