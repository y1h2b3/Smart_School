# 营养与饮食指南

本文档提供关于健康饮食、营养搭配和体重管理的专业建议。

---

## 基础营养知识

### 三大营养素

1. **碳水化合物**
   - 作用：提供能量
   - 推荐摄入：总热量的50-65%
   - 优质来源：全谷物、蔬菜、水果、豆类
   - 避免：精制糖、白面包、含糖饮料

2. **蛋白质**
   - 作用：构建和修复组织、维持免疫功能
   - 推荐摄入：总热量的10-35%（成人每天0.8-1.2g/kg体重）
   - 优质来源：瘦肉、鱼类、蛋类、豆制品、坚果
   - 运动人群：1.2-2.0g/kg体重

3. **脂肪**
   - 作用：提供能量、促进维生素吸收、维持细胞功能
   - 推荐摄入：总热量的20-35%
   - 优质来源：橄榄油、坚果、深海鱼、牛油果
   - 避免：反式脂肪、过多饱和脂肪

## 体重管理

### 减重饮食建议

**热量控制：**

- 减重速度：每周0.5-1kg为宜
- 热量缺口：每天减少500-750千卡
- 最低热量：女性不低于1200千卡/天，男性不低于1500千卡/天

**饮食原则：**

1. 增加蛋白质摄入（25-30%总热量）
2. 选择低GI碳水化合物
3. 适量健康脂肪
4. 多吃蔬菜和水果
5. 控制份量
6. 规律进餐，避免暴饮暴食

**推荐食物：**

- 蛋白质：鸡胸肉、鱼类、豆腐、鸡蛋白
- 碳水化合物：糙米、燕麦、红薯、全麦面包
- 蔬菜：绿叶蔬菜、西兰花、番茄、黄瓜
- 水果：苹果、橙子、蓝莓、草莓（适量）
- 健康脂肪：坚果、橄榄油、牛油果

### 增重饮食建议

**热量盈余：**

- 增重速度：每周0.5kg为宜
- 热量盈余：每天增加300-500千卡
- 重点：增加肌肉而非脂肪

**饮食原则：**

1. 增加进餐频率（5-6餐/天）
2. 提高蛋白质摄入（1.6-2.2g/kg体重）
3. 选择营养密集的食物
4. 适量增加健康脂肪
5. 配合力量训练

**推荐食物：**

- 高蛋白：牛肉、鸡肉、鱼类、鸡蛋、乳制品
- 复合碳水：糙米、燕麦、全麦面食、土豆
- 健康脂肪：坚果、花生酱、橄榄油、深海鱼
- 营养补充：蛋白粉、增肌粉（如需要）

## 运动营养

### 运动前饮食

**时间安排：**

- 大餐：运动前3-4小时
- 小餐：运动前1-2小时
- 零食：运动前30分钟

**推荐食物：**

- 碳水为主：香蕉、燕麦、全麦面包
- 少量蛋白质：酸奶、坚果
- 避免：高脂肪、高纤维食物

### 运动后饮食

**黄金时间：**

- 运动后30-60分钟内补充营养

**推荐比例：**

- 碳水：蛋白质 = 3:1 或 4:1

**推荐食物：**

- 碳水化合物：米饭、面条、土豆、水果
- 蛋白质：鸡胸肉、鱼类、鸡蛋、蛋白粉
- 补充水分和电解质

## 水分补充

### 每日饮水建议

**基本需求：**

- 成年男性：2.5-3.5升/天
- 成年女性：2.0-2.7升/天
- 运动人群：额外增加0.5-1升

**饮水时机：**

1. 起床后：1杯温水
2. 三餐前：1杯水
3. 运动前后：适量补充
4. 睡前1小时：少量饮水

**脱水信号：**

- 口渴
- 尿液颜色深
- 疲劳
- 头痛
- 皮肤干燥

## 特殊人群饮食建议

### 高血压人群

1. 减少钠摄入（<2300mg/天，理想<1500mg/天）
2. 增加钾摄入（香蕉、土豆、菠菜）
3. DASH饮食：多蔬果、低脂乳制品、全谷物
4. 限制酒精
5. 控制体重

### 高血脂人群

1. 减少饱和脂肪和反式脂肪
2. 增加膳食纤维（燕麦、豆类、蔬果）
3. 选择健康脂肪（深海鱼、坚果、橄榄油）
4. 限制胆固醇摄入
5. 控制体重

### 糖尿病人群

1. 控制总热量摄入
2. 选择低GI食物
3. 规律进餐，少食多餐
4. 增加膳食纤维
5. 限制简单糖
6. 监测血糖

## 健康饮食习惯

### 进餐规律

1. **三餐定时**
   - 早餐：7:00-9:00
   - 午餐：12:00-13:00
   - 晚餐：18:00-19:00

2. **早餐重要性**
   - 提供能量，启动代谢
   - 改善认知功能
   - 控制体重
   - 推荐：全谷物+蛋白质+水果

3. **晚餐建议**
   - 不宜过晚（睡前3小时前）
   - 不宜过饱（7-8分饱）
   - 清淡为主，少油少盐

### 健康烹饪方法

**推荐：**

- 蒸、煮、炖
- 烤（少油）
- 凉拌

**避免：**

- 油炸
- 煎炒（过多油）
- 烧烤（过度）

### 食物选择原则

1. **多样化**
   - 每天至少12种食物
   - 每周至少25种食物

2. **新鲜优先**
   - 选择当季食材
   - 减少加工食品

3. **色彩丰富**
   - 不同颜色的蔬果提供不同营养素

4. **适量原则**
   - 控制份量
   - 避免浪费

## 常见饮食误区

### 误区1：不吃早餐可以减肥

**真相：** 不吃早餐会降低代谢率，反而不利于减肥，还可能导致午餐过量进食。

### 误区2：水果可以无限量吃

**真相：** 水果含有果糖，过量摄入同样会导致热量超标和血糖波动。建议每天200-350克。

### 误区3：只吃蔬菜不吃肉可以减肥

**真相：** 缺乏蛋白质会导致肌肉流失，降低代谢率，反而不利于长期体重管理。

### 误区4：晚上吃碳水会发胖

**真相：** 发胖的关键是总热量摄入，而非进食时间。但建议晚餐适量，避免过饱。

### 误区5：喝果汁等于吃水果

**真相：** 果汁缺乏膳食纤维，糖分浓缩，更容易导致血糖波动和热量超标。

## 膳食补充剂

### 常见补充剂

1. **复合维生素**
   - 适用人群：饮食不均衡者
   - 注意：不能替代均衡饮食

2. **蛋白粉**
   - 适用人群：运动人群、蛋白质摄入不足者
   - 选择：乳清蛋白、大豆蛋白

3. **Omega-3脂肪酸**
   - 作用：心血管健康、抗炎
   - 来源：深海鱼油、亚麻籽油

4. **维生素D**
   - 作用：骨骼健康、免疫功能
   - 适用人群：日照不足者

5. **益生菌**
   - 作用：肠道健康、免疫调节
   - 来源：酸奶、发酵食品、补充剂

**注意事项：**

- 补充剂不能替代健康饮食
- 咨询专业人士后使用
- 注意剂量和相互作用

## 饮食与睡眠

### 促进睡眠的食物

1. **富含色氨酸：** 火鸡、鸡肉、牛奶、香蕉
2. **富含镁：** 坚果、绿叶蔬菜、全谷物
3. **富含钙：** 乳制品、豆制品
4. **复合碳水：** 燕麦、全麦面包

### 影响睡眠的食物

**避免：**

1. 咖啡因（睡前6小时）
2. 酒精（影响深度睡眠）
3. 辛辣食物（可能引起不适）
4. 高脂肪食物（消化时间长）
5. 大量液体（频繁起夜）

---

**健康饮食总结：**

- 均衡营养，多样化饮食
- 控制总热量，保持健康体重
- 规律进餐，细嚼慢咽
- 多吃蔬果，全谷物
- 适量蛋白质，健康脂肪
- 充足水分，限制糖和盐
- 健康烹饪，减少加工食品
