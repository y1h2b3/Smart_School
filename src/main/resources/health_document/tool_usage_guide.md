# 智能助手工具使用指南

本文档描述了智能助手可以使用的各种工具及其使用场景，帮助AI助手在回答用户问题时做出正确的工具调用决策。

---

## 可用工具概览

系统提供以下4类工具：

1. **文件操作工具** (FileOperationTool)
2. **网络搜索工具** (WebSearchTool)
3. **网页抓取工具** (WebScrapingTool)
4. **PDF生成工具** (PDFGenerationTool)

---

## 1. 文件操作工具 (FileOperationTool)

### 功能描述

提供文件的读取和写入功能，支持文本文件的操作。

### 可用方法

#### 1.1 读取文件 (readFile)

**功能：** 从指定文件中读取内容

**使用场景：**

- 用户询问"读取文件XXX的内容"
- 用户要求"查看文件XXX"
- 用户说"打开文件XXX看看"
- 需要获取之前保存的文件内容
- 用户询问某个已保存文件的信息

**参数：**

- `fileName`: 要读取的文件名（字符串）

**示例场景：**

- "帮我读取report.txt文件"
- "查看一下notes.txt里面写了什么"
- "打开config.json文件"

#### 1.2 写入文件 (writeFile)

**功能：** 将内容写入到指定文件

**使用场景：**

- 用户要求"保存到文件"
- 用户说"把这个内容写入文件XXX"
- 用户要求"创建一个文件XXX，内容是..."
- 需要持久化保存某些信息
- 用户要求导出或保存数据

**参数：**

- `fileName`: 要写入的文件名（字符串）
- `content`: 要写入的内容（字符串）

**示例场景：**

- "把这段文字保存到notes.txt"
- "创建一个文件叫做summary.txt，内容是..."
- "将这个配置写入config.json"

**注意事项：**

- 文件会保存在系统指定的目录中
- 如果文件已存在，会覆盖原有内容
- 支持各种文本格式（txt, json, md, csv等）

---

## 2. 网络搜索工具 (WebSearchTool)

### 功能描述

通过百度搜索引擎搜索互联网信息，获取最新的网络资源。

### 可用方法

#### 2.1 网络搜索 (searchWeb)

**功能：** 在百度搜索引擎中搜索关键词，返回前5条搜索结果

**使用场景：**

- 用户询问需要最新信息的问题（如新闻、天气、股票等）
- 用户明确要求"搜索"或"查询"
- 知识库中没有相关信息时
- 需要验证或补充信息时
- 用户询问实时数据或动态信息
- 用户询问特定网站或资源的信息

**参数：**

- `query`: 搜索关键词（字符串）

**示例场景：**

- "搜索一下电子科技大学中山学院的最新新闻"
- "查询今天广州的天气"
- "帮我搜索Python最新版本"
- "查找关于人工智能的最新研究"
- "搜索健康饮食的建议"

**不适用场景：**

- 知识库中已有明确答案的问题（如BMI计算、睡眠建议等）
- 简单的计算或逻辑推理
- 个人数据查询（如用户自己的健康数据）

**注意事项：**

- 返回的是搜索结果摘要，不是完整网页内容
- 如需完整内容，应配合网页抓取工具使用
- 搜索结果可能包含广告或不相关信息

---

## 3. 网页抓取工具 (WebScrapingTool)

### 功能描述

抓取指定URL的完整网页内容，获取HTML源代码。

### 可用方法

#### 3.1 抓取网页 (scrapeWebPage)

**功能：** 获取指定URL的完整HTML内容

**使用场景：**

- 用户提供了具体的网址，要求查看内容
- 从搜索结果中获取到URL后，需要查看详细内容
- 用户要求"打开这个网页"或"查看这个链接"
- 需要提取网页中的特定信息
- 用户要求分析某个网站的内容

**参数：**

- `url`: 要抓取的网页URL（字符串，必须是完整的URL）

**示例场景：**

- "帮我查看https://www.example.com这个网页的内容"
- "抓取这个链接的内容：https://news.example.com/article/123"
- "打开https://www.baidu.com看看"

**使用建议：**

- 通常与搜索工具配合使用：先搜索获取URL，再抓取详细内容
- 适合需要深入了解某个网页内容的场景
- 返回的是HTML源代码，可能需要进一步解析

**注意事项：**

- 需要提供完整的URL（包括http://或https://）
- 某些网站可能有反爬虫机制
- 返回的是原始HTML，可能包含大量标签

## 4. PDF生成工具 (PDFGenerationTool)

### 功能描述

将文本内容生成为PDF文档，支持中文内容。

### 可用方法

#### 4.1 生成PDF (generatePDF)

**功能：** 将给定的文本内容生成为PDF文件

**使用场景：**

- 用户要求"生成PDF"或"导出为PDF"
- 用户说"把这个内容做成PDF文档"
- 需要创建正式文档或报告
- 用户要求打印或分享文档
- 需要保存格式化的文档

**参数：**

- `fileName`: PDF文件名（字符串，建议包含.pdf后缀）
- `content`: 要写入PDF的文本内容（字符串）

**示例场景：**

- "把这份报告生成PDF文件，命名为report.pdf"
- "将这段文字导出为PDF文档"
- "创建一个PDF文件，内容是我的健康总结"
- "生成一份PDF格式的学习笔记"

**使用建议：**

- 文件名建议使用有意义的名称
- 内容可以包含换行符和中文字符
- 适合需要正式文档输出的场景

**注意事项：**

- 生成的PDF使用中文字体，支持中文显示
- PDF文件保存在系统指定目录
- 内容为纯文本，不支持复杂格式（如表格、图片等）

## 工具选择决策指南

### 何时使用文件操作工具？

✅ **应该使用：**

- 用户明确提到"文件"、"保存"、"读取"、"写入"
- 需要持久化保存信息
- 需要读取之前保存的内容

❌ **不应该使用：**

- 仅仅是回答问题，不需要保存
- 用户没有提到文件操作

### 何时使用网络搜索工具？

✅ **应该使用：**

- 需要最新的、实时的信息
- 知识库中没有相关信息
- 用户明确要求"搜索"、"查询"
- 需要外部资源或网站信息
- 涉及新闻、天气、股票等动态信息

❌ **不应该使用：**

- 知识库中已有明确答案（如健康知识、BMI标准等）
- 简单的计算或推理问题
- 用户的个人数据查询

### 何时使用网页抓取工具？

✅ **应该使用：**

- 用户提供了具体的URL
- 从搜索结果中需要获取详细内容
- 用户要求"打开链接"、"查看网页"

❌ **不应该使用：**

- 没有具体的URL
- 只需要搜索结果摘要就足够

### 何时使用PDF生成工具？

✅ **应该使用：**

- 用户明确要求"生成PDF"、"导出PDF"
- 需要创建正式文档
- 用户要求打印或分享文档

❌ **不应该使用：**

- 用户只是要求保存文本（应使用文件操作工具）
- 不需要特殊格式的文档

## 工具组合使用示例

### 场景1：搜索并保存信息

**用户请求：** "搜索一下最新的健康饮食建议，然后保存到文件"

**工具调用顺序：**

1. 使用 `WebSearchTool.searchWeb("健康饮食建议")`
2. 使用 `FileOperationTool.writeFile("health_diet.txt", 搜索结果内容)`

### 场景2：搜索、抓取并生成PDF

**用户请求：** "搜索电子科技大学中山学院的介绍，然后生成一份PDF报告"

**工具调用顺序：**

1. 使用 `WebSearchTool.searchWeb("电子科技大学中山学院")`
2. 从搜索结果中提取URL
3. 使用 `WebScrapingTool.scrapeWebPage(url)` 获取详细内容
4. 使用 `PDFGenerationTool.generatePDF("school_intro.pdf", 整理后的内容)`

### 场景3：读取文件并生成PDF

**用户请求：** "读取notes.txt文件，然后生成一份PDF"

**工具调用顺序：**

1. 使用 `FileOperationTool.readFile("notes.txt")`
2. 使用 `PDFGenerationTool.generatePDF("notes.pdf", 文件内容)`

## 重要原则

### 1. 优先使用知识库

如果问题可以通过现有知识库（如health_knowledge.md、nutrition_guide.md）回答，**不要**调用搜索工具。

**示例：**

- ❌ 用户问"BMI怎么计算？" → 不要搜索，直接使用知识库回答
- ✅ 用户问"最新的BMI标准有什么变化？" → 可以搜索获取最新信息

### 2. 明确用户意图

在调用工具前，确保理解用户的真实需求：

- 用户是想要信息，还是想要保存信息？
- 用户需要最新信息，还是一般性知识？
- 用户是否提供了具体的URL或文件名？

### 3. 合理组合工具

某些复杂任务需要多个工具配合：

- 搜索 → 抓取 → 保存
- 读取 → 处理 → 生成PDF
- 搜索 → 整理 → 写入文件

### 4. 错误处理

如果工具调用失败：

- 向用户说明失败原因
- 提供替代方案
- 不要重复调用失败的工具

## 常见问题场景

### Q: 用户问"今天天气怎么样？"

**A:** 使用 `WebSearchTool.searchWeb("今天天气")`

### Q: 用户问"BMI正常范围是多少？"

**A:** 直接使用知识库回答，**不要**调用搜索工具

### Q: 用户说"把这段话保存一下"

**A:** 使用 `FileOperationTool.writeFile(文件名, 内容)`

### Q: 用户说"帮我搜索XXX，然后保存成PDF"

**A:**

1. 使用 `WebSearchTool.searchWeb("XXX")`
2. 使用 `PDFGenerationTool.generatePDF("result.pdf", 搜索结果)`

### Q: 用户提供了一个网址，说"看看这个网页"

**A:** 使用 `WebScrapingTool.scrapeWebPage(url)`

### Q: 用户问"我之前保存的文件里写了什么？"

**A:** 使用 `FileOperationTool.readFile(文件名)`

---

## 总结

正确使用工具的关键是：

1. **理解用户意图** - 用户真正需要什么？
2. **优先知识库** - 能用知识库就不要搜索
3. **选择合适工具** - 根据场景选择最合适的工具
4. **合理组合** - 复杂任务需要多工具配合
5. **清晰反馈** - 告诉用户你在做什么，结果如何

通过合理使用这些工具，可以为用户提供更强大、更灵活的智能助手服务。
