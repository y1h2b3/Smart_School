# SmartCampus - 智慧校园管理系统

## 📖 项目概述

**SmartCampus** 是一个基于 Spring Boot 的智慧校园一体化管理平台后端服务。它旨在为学生、教师和家长提供便捷的校园服务，核心功能包括健康监测、在线药品订购、支付宝支付集成以及基于 AI 的健康建议。

---
