### 1.student

student表为学生表，用于学生信息。具体表结构如下：

| 字段名         | 数据类型        | 说明     | 备注              |
|-------------|-------------|--------|-----------------|
| id          | bigint      | 主键     | 自增              |
| type        | INT         | 人员     | 1学生，2老师，3后勤，4家长 |
| device_id   | varchar(32) | 设备id   | 逻辑外键            |
| parent_id   | INT         | 家长id   | 逻辑外键            |
| student_id  | INT         | 学号     | 逻辑外键            |
| teacher_id  | INT         | 班主任    | 逻辑外键            |
| calss       | varchar(32) | 班级     |                 |
| name        | varchar(32) | 姓名     |                 |
| username    | varchar(32) | 用户名    | 唯一              |
| password    | varchar(64) | 密码     |                 |
| phone       | varchar(11) | 手机号    |                 |
| sex         | varchar(2)  | 性别     |                 |
| create_time | datetime    | 创建时间   |                 |
| update_time | datetime    | 最后修改时间 |                 |
